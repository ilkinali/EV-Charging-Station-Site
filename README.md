# ⚡ EV Charging Station Site

**EV Charging Station Site** is a modern and responsive web interface designed to showcase electric vehicle charging station services, promote sustainability, and engage environmentally conscious users.

---

## 🚀 Features

- ⚡ Interactive and informative homepage
- 📍 Station locations and booking prompts
- 🌱 Clean, green, and responsive design
- 📱 Mobile-friendly layout

---

## 🔧 Built With

- HTML5
- CSS3 (Flexbox/Grid)
- JavaScript (Vanilla)
- Font Awesome (Icons)

---

## 🔐 Authentication *(Planned)*
- Google OAuth 2.0 login
- User dashboard for personalized services
